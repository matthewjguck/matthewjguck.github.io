❓ TROUBLESHOOTING
================================================================================

Images not loading?
  → Check folder structure matches: assets/images/ and assets/resources/
  → Verify file names are exact (case-sensitive)
  → Check file paths in HTML (should be relative: assets/...)

Styles look wrong?
  → Clear browser cache (Ctrl+Shift+Delete or Cmd+Shift+Delete)
  → Try different browser
  → Check that all CSS is intact in index.html

File size too large?
  → Folder is ~13 MB (mostly images)
  → Acceptable for portfolio hosting
  → Can optimize by compressing JPGs further if needed

Links not working?
  → This is intentional for portfolio demo
  → To enable: change href="#" to real URLs
  → Remove "cursor: default;" from CSS if you add real links
